# ADR-0001: 采用 Go 语言与内嵌 Web 控制台重构桌面辅助

## 决策背景

原版辅助工具为 Windows MFC / C++ 开发的桌面程序，强绑定 Windows 桌面窗口环境，存在内存占用不可控、无法无头部署（Headless / Docker / NAS）、网络超时与凭据刷新机制陈旧等问题。

## 架构决策

全面采用 **Go (Golang)** 进行重构，并使用 **Go-Embed (`go:embed`) 内嵌 Web 控制台** 替代原生桌面 GUI：

1. **核心运行时**：使用 Go 单静态二进制分发，具备原生跨平台支持（Windows / Linux / macOS / Docker）、极低内存占用以及原生轻量协程（Goroutine）高并发模型。
2. **交互界面**：内嵌轻量前端资源，程序启动后在本地监听管理端口，用户直接通过本地浏览器访问 Web 控制台进行多账号与任务管理。
3. **协议实现**：纯脱机网络封包逆向还原，彻底摆脱游戏客户端窗口句柄依赖与内存挂钩（Hook）。

## 结果影响

- **收益**：可无缝运行于 NAS、云服务器、Docker 或本地后台；单文件双击即用；网络与协议逻辑天然高并发。
- **代价**：失去了原版基于 Windows 原生控件的浮窗交互习惯，初次使用需打开浏览器访问本地控制台。
