# ADR-0007: 三级漏斗式内存题库检索与资产双向探测机制

## 决策背景

《神仙道》中包含金榜题名、仙履奇缘、刮刮卡等高频问答活动，限时倒计时要求高（通常 5~10 秒内作答）。题库文件达数万条，且常伴随标点差异或跨版本细微字形错漏；同时数据资产（`Pieb.db`、`answers.txt`）需兼顾开箱即用与兼容本地既有环境。

## 架构决策

建立 **三级漏斗式内存检索算法** 与 **资产目录双向探测加载机制**：

1. **三级漏斗式内存检索算法**：
   - 第一级（归一化精准查表）：去除标点、英文字符与空格后进行内存 Hash 查找，耗时 < 0.1ms，命中率 90%+；
   - 第二级（实体关键词交集）：当未直接命中时，提取题干核心名词倒排索引求交集；
   - 第三级（编辑距离兜底）：使用 Levenshtein 相似度算法，相似度 > 0.7 予以召回，低于阈值安全跳过。
2. **资产双向探测与工程纳管**：
   - 随工程维护 `./data/` 目录，纳管基础数据库与题库；
   - 启动时优先加载 `./data/`，若缺失则自动回退探测本地历史目录（`D:\Software\疯玩神仙道\`），保障任意运行环境的鲁棒性。

## 结果影响

- **收益**：毫秒级超快响应与极高答题正确率；资产零配置开箱即用。
- **代价**：首次加载题库需占用数 MB 运行内存建立倒排索引。
