# ADR-0005: 全量活动玩法矩阵平铺骨架与双模配置模型

## 决策背景

原版辅助涵盖日常福利、农场取经、竞技扫荡、帮派社交等 30 余种功能细项（`01.ini` / `pieb.ini`）。若逐个零散增加，会导致架构频繁变动；同时老版参数极其琐碎，直接暴露会严重破坏现代 Web 控制台的用户体验。

## 架构决策

全面建立 **全量活动玩法矩阵 (Activity Matrix)** 骨架，并配套 **双模配置体系 (Dual-Mode Config)**：

1. **全量平铺注册体系**：定义标准统一的 `Routine` 接口（标识符、优先级、调度策略、执行闭包、前置依赖检查），首批建立 30+ 玩法的统一骨架目录，使所有玩法拥有标准化生命周期。
2. **双模配置模型**：
   - **基础推荐层（Default Mode）**：普通用户只需在 Web 控制台启用相应玩法，系统自动应用最优产出预设；
   - **专家高级层（Expert Mode）**：展开抽屉/折叠卡片后，可针对特定玩法细项（如保留体力上限、购买物品阈值、指定护送类型等）进行微调。
3. **内存题库检索引擎**：对仙履奇缘与金榜题名采用内存哈希 + 模糊相似度三级漏斗检索，保障毫秒级无延迟答题。

## 结果影响

- **收益**：全量玩法具备清晰的统一规范扩展槽位；配置兼顾新手极简体验与老玩家深度调优需求。
- **代价**：初期需一次性铺设 30+ 模块的接口骨架与 YAML 契约定义。
