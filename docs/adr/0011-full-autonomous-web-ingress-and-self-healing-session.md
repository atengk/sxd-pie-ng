# ADR-0011: 全自治 Web 原生凭据流水线与自愈会话状态机

## 决策背景

《神仙道》传统挂机方案深度耦合外部专用工具（`疯玩自动更新器.exe`、`pie.exe`）及中间落盘文件（`user.ini`），不仅丧失跨平台部署能力，且在外部工具失效或凭据过期时无法实现无人值守自愈。用户要求系统做到零外部程序依赖，仅凭配置文件中的平台账号密码实现全自动凭据提取与长连接握手。

## 架构决策

1. **三阶段全自治 Web 换票驱动 (Autonomous Ingress)**：
   - 彻底废除对任何外部可执行文件或磁盘 INI 的依赖，所有流程均在 Go 运行时内存中以原生 HTTP 完成：
     - **第一阶段 (POST)**：向平台网关 `login.php` 提交身份凭据，捕获平台会话认证 Cookie（`fengwanyx_code` 等）；
     - **第二阶段 (GET)**：向 `game/game.php` 请求区服网关入口，捕获 302 临时重定向目标 `login_api.php`；
     - **第三阶段 (GET)**：带跨域 Cookie 访问区服 `login_api.php`，解析响应 Set-Cookie 中的 `login_time_sxd_xxxxxxxx`、`login_hash_sxd_xxxxxxxx`、`_time`、`_hash` 与 `user`（授权码 `code`），组装成结构化双轨凭据 `*Ticket`。
2. **端到端自动连接与网关直连 (Autonomous Connect)**：
   - 服务启动时自动检测角色登录态，无感触发换票驱动，自动映射已知游戏 TCP 网关（如 `49.232.196.100:8381`）并建立 Socket 长连接。
3. **自愈会话状态机 (Self-Healing Session)**：
   - 遭遇服务端主动断开、网络波动 EOF 或时效票据（TTL 2小时）失效时，会话状态机自动调度凭据缓存刷新，重新换取新票据并重新发起 TCP 认证握手，实现无间断自愈。

## 结果影响

- **收益**：项目成为 100% 独立自主的纯 Go 服务端程序，开箱即用，支持 Linux/Docker/Windows 等任意操作系统，实现真正的全自动无人值守挂机。
- **代价**：平台前端登录 API 改版时，需在平台驱动层进行对应的 HTTP 链路升级维护。
